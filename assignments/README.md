# Assignments

This folder contains all course assignments.

## Structure

Each assignment should be placed in its own subdirectory:

```
assignments/
├── assignment-01/
│   ├── README.md      # Description and instructions
│   └── ...            # Source files
├── assignment-02/
│   └── ...
└── ...
```

## Guidelines

- Name folders using the format `assignment-<number>` (e.g., `assignment-01`).
- Include a `README.md` in each subdirectory describing the task and your solution.
- Submit your work via a Pull Request before the deadline.
