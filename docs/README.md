# Documentation

This folder contains shared documentation, references, and resources for the course.

## What Goes Here

- Setup guides and environment configuration
- Shared notes and summaries
- References and useful links
- Team agreements and decisions

## Guidelines

- Use Markdown (`.md`) for all documents.
- Use clear, descriptive filenames (e.g., `setup-guide.md`, `git-workflow.md`).
- Keep documents up to date as the course progresses.
