# Labs

This folder contains all lab exercises and practicals from the course.

## Structure

Each lab should be placed in its own subdirectory:

```
labs/
├── lab-01/
│   ├── README.md      # Lab instructions and notes
│   └── ...            # Source files
├── lab-02/
│   └── ...
└── ...
```

## Guidelines

- Name folders using the format `lab-<number>` (e.g., `lab-01`).
- Include a `README.md` in each subdirectory with the lab objectives and your observations.
- Keep your solutions self-contained within the lab folder.
