# Projects

This folder contains all course projects (e.g., mid-term and final projects).

## Structure

Each project should be placed in its own subdirectory:

```
projects/
├── project-midterm/
│   ├── README.md      # Project description, requirements, and usage
│   └── ...            # Source files
├── project-final/
│   └── ...
└── ...
```

## Guidelines

- Use descriptive folder names (e.g., `project-midterm`, `project-final`).
- Each project must include a `README.md` covering:
  - Project description
  - How to run / build the project
  - Team members who contributed
  - Any known issues or limitations
